# Sales Analytics — SQL-проект

## О проекте

Portfolio-проект по анализу продаж с использованием **PostgreSQL**.

В рамках проекта была создана реляционная база данных, содержащая информацию о клиентах, заказах, товарах и позициях заказов. На основе этих данных выполнен анализ продаж, клиентов, товаров и заказов с использованием SQL.

Проект ориентирован на задачи, которые могут встречаться в работе **Junior Data Analyst**.

## Бизнес-задачи

В проекте рассматриваются следующие направления анализа:

### Продажи

* общий объём выручки;
* количество заказов;
* средний чек;
* динамика выручки по месяцам;
* сравнение выручки текущего и предыдущего месяца.

### Клиенты

* клиенты с наибольшей выручкой;
* клиенты с выручкой выше заданного значения;
* клиенты без заказов;
* средний чек по каждому клиенту;
* рейтинг клиентов по выручке.

### Товары

* топ-5 товаров по выручке;
* выручка по категориям;
* количество проданных единиц по категориям.

### Заказы

* топ-3 заказа по стоимости;
* стоимость заказов вместе с информацией о клиентах.

**customers** — информация о клиентах

| Поле        | Описание    |
| ----------- | ----------- |
| customer_id | ID клиента  |

| Поле         | Описание        |

**orders** — информация о заказах

| Поле        | Описание    |
| ----------- | ----------- |
| order_id    | ID заказа   |
| customer_id | ID клиента  |

**order_items** — состав заказов

| Поле       | Описание   |
| ---------- | ---------- |
| order_id   | ID заказа  |
| product_id | ID товара  |

## Примеры анализа

### Топ-5 клиентов по выручке

```sql
SELECT
    c.customer_id,
    c.name,
    SUM(p.price * oi.quantity) AS total_revenue
FROM customers c
JOIN orders o
    ON c.customer_id = o.customer_id
JOIN order_items oi
    ON o.order_id = oi.order_id
JOIN products p
    ON oi.product_id = p.product_id
GROUP BY
    c.customer_id,
    c.name
ORDER BY total_revenue DESC
LIMIT 5;
```

### Динамика месячной выручки

```sql
SELECT
    DATE_TRUNC('month', o.order_date) AS month,
    SUM(p.price * oi.quantity) AS total_revenue
FROM orders o
JOIN order_items oi
    ON o.order_id = oi.order_id
JOIN products p
    ON oi.product_id = p.product_id
GROUP BY DATE_TRUNC('month', o.order_date)
ORDER BY month;
```
