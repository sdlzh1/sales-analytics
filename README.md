# Sales Analytics — SQL + Power BI

## О проекте

Портфолио-проект по анализу продаж с использованием **PostgreSQL** и **Power BI**.

В рамках проекта создана реляционная база данных с информацией о клиентах, заказах, товарах и позициях заказов. С помощью SQL проведён анализ продаж, клиентов, товаров и заказов. На основе полученных данных создан интерактивный аналитический дашборд в Power BI.

Проект ориентирован на типовые задачи, которые могут встречаться в работе **Junior Data Analyst**.

---

## Бизнес-задачи

### Продажи

- расчёт общей выручки;
- количество заказов;
- средний чек;
- динамика выручки по месяцам;
- сравнение показателей между периодами.

### Клиенты

- определение клиентов с наибольшей выручкой;
- поиск клиентов с выручкой выше заданного значения;
- поиск клиентов без заказов;
- расчёт среднего чека по клиентам;
- ранжирование клиентов по выручке;
- анализ количества заказов и выручки клиентов.

### Товары

- определение топ-5 товаров по выручке;
- анализ выручки по категориям;
- анализ количества проданных единиц;
- сравнение товаров по выручке и объёму продаж.

### Заказы

- определение наиболее дорогих заказов;
- расчёт стоимости каждого заказа;
- анализ заказов вместе с информацией о клиентах.

## Примеры SQL-запросов

### Топ-5 клиентов по выручке

```sql
SELECT
    c.customer_id,
    c.name,
    SUM(p.price * oi.quantity) AS total_revenue
FROM customers c
JOIN orders o
    ON c.customer_id = o.customer_id
JOIN order_items oi
    ON o.order_id = oi.order_id
JOIN products p
    ON oi.product_id = p.product_id
GROUP BY
    c.customer_id,
    c.name
ORDER BY total_revenue DESC
LIMIT 5;
```

### Динамика месячной выручки

```sql
SELECT
    DATE_TRUNC('month', o.order_date) AS month,
    SUM(p.price * oi.quantity) AS total_revenue
FROM orders o
JOIN order_items oi
    ON o.order_id = oi.order_id
JOIN products p
    ON oi.product_id = p.product_id
GROUP BY DATE_TRUNC('month', o.order_date)
ORDER BY month;
```
